# 🌿 Henna by Husaina ✨

Welcome to **Henna by Husaina**, an exquisite showcase of contemporary and traditional mehndi artistry. This beautifully crafted, high-performance portfolio is designed to bring the elegance and precision of henna design into the digital world.

![Henna Art](public/favicon.svg)

## 🌟 Features
- **Immersive 3D Carousel:** A stunning interactive 3D gallery to browse intricate designs.
- **Curtain Reveal Animation:** A theatrical curtain-opening experience upon scrolling to the portfolio section.
- **Smooth Scrolling & 60FPS Animations:** Carefully optimized to ensure buttery smooth performance.
- **Fully Responsive Design:** Flawless experience across mobile, tablet, and desktop devices.
- **Rich Media Integration:** High-quality videos and images presented with minimal layout shifting.

## 🚀 Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion, GSAP
- **Icons:** Lucide React
- **Deployment:** Vercel
